# Exported prediction models: past-year telehealth use (NHIS)

Models developed on the NHIS 2024 adult file (80% training split, seed 2026)
and temporally validated on the NHIS 2025 adult file. Generated by
`nhis_telehealth_prediction_final.Rmd`; see that document for methods.

| File | Contents |
|---|---|
| `model_coefficients.csv` | Intercept and coefficients (log-odds scale) of the theory-based, theory-based BIC and primary (stepwise BIC) logistic models, with standard errors; nonzero penalized coefficients of the two group lasso models (no standard errors) |
| `spline_knots.csv` | Interior and boundary knots of the natural splines `ns(age, df = 3)` and `ns(pov_ratio, df = 3)` (2024 training data) |
| `factor_levels.csv` | Levels of each categorical variable; the first level is the reference |
| `coding_dictionary.csv` | Rules that turn raw NHIS codes into the model variables, including nonresponse and skip handling |
| `predict_from_csv.R` | `predict_from_csv(data, model)`: predicted probabilities from the files above |
| `xgb_full_pool.json`, `xgb_features.csv`, `xgb_settings.csv` | XGBoost model (xgboost JSON format), its input columns (R `model.matrix` dummy coding) and tuning settings |

Input data must be coded as in the analysis: age in years, income-to-poverty
ratio capped at 11, categorical variables labelled as in `factor_levels.csv`.
Models were fit without survey weights. Predictions describe the NHIS adult
population of 2024<U+2013>2025 and have not been validated outside this survey.
Raw NHIS files are not included; they are available from the National
Center for Health Statistics.
