A note on payments

Payments are amounts paid, not charges. Released values include imputation and zero-payment visits. Out-of-pocket payments refer to the family payment variable; these are not estimates of savings from telehealth.

Three sources, distinct populations

The sources answer complementary questions and are not pooled into a single telehealth rate. This overview describes the verified snapshot. Optional live CMS updates are labelled separately in States & access.

Transparency by design

From source file to display

Missing is not zero

Suppressed, unknown, inapplicable, and missing values stay distinct. Survey outcome nonresponse is excluded from that outcome’s denominator and reported separately.

Uncertainty stays visible

Survey estimates use weights, strata, and primary sampling units. Confidence intervals show sampling uncertainty; they do not remove nonresponse or measurement bias.

Reproducible releases

Source links, retrieval dates, file checksums, and analysis scripts document how the estimates were produced. The dashboard opens with a verified data snapshot. The CMS update button can load current descriptive data into the session; these values are labelled as not revalidated.

Analytical scope

Explore geographic patterns, population differences, visit payments, and adjusted cross-sectional associations. The estimates describe use and payments within each source population.
